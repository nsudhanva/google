# Next Greater element i

## Problem Info
- **Link**: [Next Greater element i](https://leetcode.com/problems/next-greater-element-i/)
- **Category**: Stacks & Queues
- **Difficulty**: Easy
- **Status**: DONE

## Approach
### Data Structure
- Stack

### Time Complexity
- O(n)

## Things to Remember
- push element to stack if it is decreasing order.
- if not, pop and put the larger element in a map to be able to access quickly.

## Additional Notes
- Bruteforce is to check for every element, the next largest one - O(mn)
